# レガリア王立魔術学院 ― 寮分け＆人物共鳴診断

AIキャラクターチャット創作のための、寮分け・人物診断ツール。
全18問に答えると、所属寮に加えて学院の28人物から「性格が近い人物」と「相性の良い人物」を判定し、公式設定資料と共にキャラクター設定の「スターターキット」を自動生成します。

## 特徴

- **公式設定資料を反映** — 4寮の紋章・カラー・施設・雰囲気、寮間の関係性まで設定画像から取り込み済み。
- **完全クライアントサイド** — サーバー不要・APIキー不要。GitHub Pages で無料公開できます。
- **18問の診断** — 価値観・弱点・魔法の発動トリガー・生い立ち・行きつけの場所・寮間の力学など、キャラの「芯」を引き出す質問。
- **28人物との共鳴診断** — 4寮の生徒、教師、特殊人物を同じ候補として扱い、「似ている人物」と「相性の良い人物」を独立して判定。双子は1組として扱います。
- **キャラ生成エンジン** — 1位の寮＋2位の寮＋回答フラグ（内向/外向・恋愛観・朝型夜型・口調）を組み合わせて、アーキタイプ／性格／魔法系統と発動トリガー／一人称・口調サンプル／ビジュアル方向性／行きつけの場所／学年の立ち位置／他寮との因縁フックを提案。
- **スターターキット再生成** — 人物診断は保ったまま、同じ診断結果から何度でも別案を引けます。

## 4つの寮

| 寮 | 特化 | カラー | キーワード |
|---|---|---|---|
| ⚔️ マキナ寮 (MACHINA) | 戦闘 | 赤 | 仲間想い・熱血・直感型 |
| 🜿 コルウス寮 (CORVUS) | 研究・異端 | 紫/黒 | 知識欲・個人主義・夜型 |
| ⚜ メディシス寮 (MEDICIS) | 医療・外交 | 白金/翠 | 計算高さ・博愛の仮面・支配欲 |
| ✦ ルミエール寮 (LUMIERE) | 芸術・魅了 | 金/紅紫 | 感性至上・カリスマ・美への執着 |

## ローカルで確認する

- いちばん簡単：`standalone.html` をブラウザで開くだけ（画像込みで完結）。
- もしくは `index.html` を簡易サーバー経由で：
  ```bash
  python3 -m http.server 8000   # → http://localhost:8000
  ```

## GitHub Pages で公開する

1. このリポジトリ（`index.html` と `assets/` を含む）を GitHub に push
2. リポジトリの **Settings → Pages** を開く
3. **Source** を `Deploy from a branch`、`main` ブランチの `/ (root)` を選択
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## カスタマイズ

`index.html` 内の以下を編集すれば内容を変えられます。

- `DORMS` — 寮の設定・色・モットー・説明文・参照画像
- `QUESTIONS` — 質問と選択肢、各選択肢の配点（`s`）と隠しフラグ（`f`）
- `ANSWER_TAGS` — 各回答を人物診断用の気質へ変換する対応表
- `CHARACTERS` — 28人物の紹介、診断シグナル、相性シグナル
- `TAG_LABELS` — 結果画面に表示する気質名
- `KIT` — 寮ごとのキャラ生成プール（アーキタイプ・性格・魔法・ビジュアル・行きつけの場所）
- `RIVALRY` — 他寮との因縁テンプレート
- `SPEECH` — 一人称・口調サンプル
- `GRADES` — 学年ごとの立ち位置

配点は「その選択肢を選んだら各寮に何ポイント入るか」。1問あたり主寮へ最大3pt。
画像を差し替える際は `assets/` 内のファイルを置き換え、編集後は `standalone.html` を再生成してください。
